📘 Dokumentasi API Authentication - E-Office ST/SK Dekan
🔐 Overview
Backend menggunakan Better Auth untuk sistem autentikasi yang aman dan modern. Session-based authentication dengan cookie better-auth.session_token.

🌐 Base URL
Local: http://localhost:3079
Network: http://192.168.18.36:3079 (sesuaikan dengan IP dari console log)

🔑 Session Management
Cookie Details
Name: better-auth.session_token
HttpOnly: true (tidak bisa diakses JavaScript)
Secure: true (hanya HTTPS di production)
SameSite: Lax
Max-Age: 604800 (7 hari)
Session Update
Session akan auto-refresh setiap 24 jam jika user masih aktif.

🛡️ Protected Endpoints
Semua endpoint di luar /api/auth/* memerlukan autentikasi.

Cara menggunakan di Frontend:

Axios (Recommended)
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:3079',
  withCredentials: true // PENTING: Agar cookie ikut terkirim
});

// Login
const login = async (email: string, password: string) => {
  const response = await api.post('/api/auth/sign-in/email', {
    email,
    password
  });
  return response.data;
};

// Get Dashboard (Protected)
const getDashboard = async () => {
  const response = await api.get('/dash');
  return response.data;
};

Fetch API
// Login
const login = async (email: string, password: string) => {
  const response = await fetch('http://localhost:3079/api/auth/sign-in/email', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    credentials: 'include', // PENTING: Agar cookie ikut
    body: JSON.stringify({ email, password })
  });
  return response.json();
};

// Get Dashboard (Protected)
const getDashboard = async () => {
  const response = await fetch('http://localhost:3079/dash', {
    credentials: 'include' // PENTING
  });
  return response.json();
};
