📝 Dokumentasi API Submission - E-Office ST/SK Dekan

🎯 Overview
Modul Submission menangani pengajuan surat baru oleh Mahasiswa dan Dosen. Menyediakan endpoint untuk membuat, melihat, mengubah, membatalkan pengajuan, serta mengelola lampiran dokumen pendukung.

🌐 Base URL
Local: http://localhost:3079
Network: http://192.168.18.36:3079

🔐 Authentication
- Endpoint `/letter-types` dan `/letter-types/:id` → PUBLIC (tidak perlu login)
- Endpoint lainnya → PRIVATE (perlu login sebagai MAHASISWA atau DOSEN)
- Cookie: better-auth.session_token harus terkirim

⚠️ IMPORTANT: Setelah login, wajib panggil GET /me untuk mendapatkan informasi user lengkap termasuk role.

6. Create Submission with Files (PRIVATE)
═══════════════════════════════════════════════════════════════════════════════

Membuat pengajuan surat baru sekaligus upload lampiran (multipart/form-data).

Endpoint: POST /api/submission/with-files

Headers:
Content-Type: multipart/form-data
Cookie: better-auth.session_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Request Body (FormData):
- letterTypeId: "cmktblwa50043o9rcfmw92xth"
- nama: "Ahmad Budi Santoso"
- nim: "24060121130001"
- departemen: "Departemen Informatika"
- programStudi: "S1 Informatika"
- jenisSurat: "SURAT_TUGAS"
- keperluan: "Mengikuti Lomba Competitive Programming"
- judulAcara: "Lomba Competitive Programming Nasional"
- tanggalAcara: "2026-02-15T09:00:00Z" (ISO datetime format)
- durasiAcara: "2 hari" (optional)
- lokasiAcara: "Jakarta Convention Center"
- butuhTtdKadep: true
- targetSigner: "DEKAN"
- requestKadepSign: true
- attachments[]: File (Max 5 files, each max 5MB)
- attachments[]: File

File Constraints:
- Max files: 5
- Max size per file: 5MB
- Allowed formats: PDF, JPG, JPEG, PNG
- Field name: attachments[] (array)

Request Example (JavaScript):
const formData = new FormData();
formData.append('letterTypeId', 'cmktblwa50043o9rcfmw92xth');

formData.append('attachments', file1); // File object (optional, max 5 files)

// services/submission.service.ts
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:3079',
  withCredentials: true // WAJIB untuk cookie
});

export const submissionService = {
  // Get letter types (public)
  getLetterTypes: async () => {
    const response = await api.get('/api/submission/letter-types');
    return response.data;
  },

  // Get letter type detail with schema (public)
  getLetterTypeById: async (id: string) => {
    const response = await api.get(`/api/submission/letter-types/${id}`);
    return response.data;
  },

  // Get my submissions
  getMySubmissions: async (params?: {
    page?: number;
    limit?: number;
    status?: string;
    search?: string;
  }) => {
    const response = await api.get('/api/submission', { params });
    return response.data;
  },

  // Get submission detail
  getSubmissionById: async (id: string) => {
    const response = await api.get(`/api/submission/${id}`);
    return response.data;
  },

  // Create submission (without files)
  createSubmission: async (data: {
    letterTypeId: string;
    formData: any;
    signatureConfig: any;
  }) => {
    const response = await api.post('/api/submission', data);
    return response.data;
  },

  // Create submission with files
  createSubmissionWithFiles: async (formData: FormData) => {
    const response = await api.post('/api/submission/with-files', formData, {
      headers: { 'Content-Type': 'multipart/form-data' }
    });
    return response.data;
  },

  // Update submission
  updateSubmission: async (id: string, data: any) => {
    const response = await api.put(`/api/submission/${id}`, data);
    return response.data;
  },

  // Cancel submission
  cancelSubmission: async (id: string, reason: string) => {
    const response = await api.post(`/api/submission/${id}/cancel`, { reason });
    return response.data;
  },

  // Upload attachment
  uploadAttachment: async (id: string, file: File, description?: string) => {
    const formData = new FormData();
    formData.append('file', file);
    if (description) formData.append('description', description);
    
    const response = await api.post(`/api/submission/${id}/attachments`, formData, {
      headers: { 'Content-Type': 'multipart/form-data' }
    });
    return response.data;
  },

  // Get attachment download URL
  getAttachmentDownloadUrl: async (letterId: string, attachmentId: string) => {
    const response = await api.get(`/api/submission/${letterId}/attachments/${attachmentId}/download`);
    return response.data;
  },

  // Delete attachment
  deleteAttachment: async (letterId: string, attachmentId: string) => {
    const response = await api.delete(`/api/submission/${letterId}/attachments/${attachmentId}`);
    return response.data;
  }
};

  code: string;
  category: string;
}

export const SubmissionForm = () => {
  const [letterTypes, setLetterTypes] = useState<LetterType[]>([]);
  const [selectedType, setSelectedType] = useState('');
  const [formData, setFormData] = useState({
    nama: '',
    nim: '',
    departemen: '',
    programStudi: '',
    jenisSurat: 'SURAT_TUGAS',
    keperluan: '',
    judulAcara: '',
    tanggalAcara: '',
    durasiAcara: '',
    lokasiAcara: '',
    butuhTtdKadep: false
  });
  const [files, setFiles] = useState<File[]>([]);
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  useEffect(() => {
    loadLetterTypes();
  }, []);

  const loadLetterTypes = async () => {
    try {
      const response = await submissionService.getLetterTypes();
      setLetterTypes(response.data.letterTypes);
    } catch (err) {
      setError('Gagal memuat jenis surat');
    }
  };

  const handleSubmit = async (e: React.FormEvent) => {

    setLoading(true);
    setError('');

        const formDataObj = new FormData();
        formDataObj.append('letterTypeId', selectedType);
        
        // Append form data
        Object.entries(formData).forEach(([key, value]) => {
          formDataObj.append(key, String(value));
        });
        
        // Append signature config
        formDataObj.append('targetSigner', 'DEKAN');
        formDataObj.append('requestKadepSign', String(formData.butuhTtdKadep));
        
        // Append files
        files.forEach(file => {
          formDataObj.append('attachments', file);
        });
        
        await submissionService.createSubmissionWithFiles(formDataObj);
      } else {
        // Create without files
        await submissionService.createSubmission({
          letterTypeId: selectedType,
          formData,
          signatureConfig: {
            targetSigner: 'DEKAN',
            requestKadepSign: formData.butuhTtdKadep
          }
        });
      }
      
      alert('Pengajuan berhasil dibuat!');
      // Redirect or reset form

      setError(err.response?.data?.message || 'Gagal membuat pengajuan');

      setLoading(false);
    }

// components/SubmissionList.tsx
import { useEffect, useState } from 'react';
import { submissionService } from '../services/submission.service';

export const SubmissionList = () => {
  const [submissions, setSubmissions] = useState([]);
  const [loading, setLoading] = useState(true);
  const [page, setPage] = useState(1);
  const [totalPages, setTotalPages] = useState(1);

  useEffect(() => {
    loadSubmissions();
  }, [page]);

  const loadSubmissions = async () => {
    setLoading(true);
    try {
      const response = await submissionService.getMySubmissions({ page, limit: 10 });
      setSubmissions(response.data.letters);
      setTotalPages(response.data.pagination.totalPages);
    } catch (err) {
      console.error('Failed to load submissions:', err);
    } finally {
      setLoading(false);
    }
  };

  const handleCancel = async (id: string) => {
    const reason = prompt('Alasan pembatalan:');
    if (!reason || reason.length < 10) {
      alert('Alasan minimal 10 karakter');
      return;
    }

    try {
      await submissionService.cancelSubmission(id, reason);
      alert('Pengajuan berhasil dibatalkan');
      loadSubmissions();
    } catch (err: any) {
      alert(err.response?.data?.message || 'Gagal membatalkan pengajuan');
    }
  };

  if (loading) return <div>Loading...</div>;

  return (
    <div>
      <h2>Pengajuan Saya</h2>
      <table>
        <thead>
          <tr>
            <th>Tanggal</th>
            <th>Jenis Surat</th>
            <th>Keperluan</th>
            <th>Status</th>
            <th>Aksi</th>
          </tr>
        </thead>
        <tbody>
          {submissions.map((letter: any) => (
            <tr key={letter.id}>
              <td>{new Date(letter.submittedAt).toLocaleDateString('id-ID')}</td>
              <td>{letter.letterType.name}</td>
              <td>{letter.submissionValues.keperluan}</td>
              <td>{letter.statusDisplay}</td>
              <td>
                <button onClick={() => window.location.href = `/submission/${letter.id}`}>
                  Detail
                </button>
                {letter.canCancel && (
                  <button onClick={() => handleCancel(letter.id)}>
                    Batalkan
                  </button>
                )}
              </td>
            </tr>
          ))}
        </tbody>
      </table>

      {/* Pagination */}
      <div>
        <button disabled={page === 1} onClick={() => setPage(page - 1)}>
          Previous
        </button>
        <span>Page {page} of {totalPages}</span>
        <button disabled={page === totalPages} onClick={() => setPage(page + 1)}>
          Next
        </button>
      </div>
    </div>
  );
};

📌 Important Notes
═══════════════════════════════════════════════════════════════════════════════

1. **Authentication**: 
   - Endpoint `/letter-types` adalah PUBLIC (tidak perlu login)
   - Semua endpoint lainnya adalah PRIVATE (perlu login sebagai MAHASISWA atau DOSEN)

2. **Cookie Management**:
   - Frontend WAJIB mengirim cookie better-auth.session_token
   - Axios: gunakan withCredentials: true
   - Fetch: gunakan credentials: 'include'

3. **File Upload**:
   - Max 5 files per submission
   - Max 5MB per file
   - Hanya PDF, JPG, PNG yang diperbolehkan
   - Gunakan multipart/form-data

4. **Status Lifecycle**:
   - SUBMITTED → Bisa cancel, tidak bisa edit
   - KAPRODI_REVIEW → Tidak bisa cancel/edit
   - FAKULTAS_* → Tidak bisa cancel/edit
   - COMPLETED → Bisa download surat final
   - CANCELLED → Final state, tidak ada aksi

5. **Permissions**:
   - Hanya pembuat surat yang bisa update/cancel
   - Update hanya bisa saat status SUBMITTED atau KAPRODI_REVIEW (sebelum masuk fakultas)
   - Cancel hanya bisa sebelum masuk proses fakultas

6. **Attachments**:
   - Bisa diupload saat create atau setelah create
   - Bisa dihapus selama status masih memungkinkan
   - Download menggunakan signed URL (valid 1 jam)

7. **Validation**:
   - Frontend WAJIB validasi input sebelum submit
   - Backend juga melakukan validasi ulang
   - Error messages akan berisi detail field yang error

8. **Best Practices**:
   - Cache letter types di frontend (tidak perlu fetch ulang)
   - Gunakan loading states untuk UX yang baik
   - Show progress bar untuk file upload
   - Implementasi retry logic untuk network errors
   - Log errors untuk debugging (tapi jangan expose sensitive data)
