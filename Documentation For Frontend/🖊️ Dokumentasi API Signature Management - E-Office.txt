🖊️ Dokumentasi API Signature Management - E-Office ST/SK Dekan

🎯 Overview
Modul Signature Management menyediakan fitur untuk menyimpan, mengelola, dan menggunakan kembali tanda tangan digital. User dapat mengunggah tanda tangan dari file atau canvas drawing, menyimpannya sebagai template, dan menggunakannya untuk penandatanganan dokumen tanpa perlu upload ulang.

🌐 Base URL
Local: http://localhost:3079
Network: http://192.168.18.36:3079

🔐 Authentication
- Semua endpoint PRIVATE (perlu login)
- User hanya dapat mengakses tanda tangan miliknya sendiri
- Cookie: better-auth.session_token harus terkirim

⚠️ IMPORTANT: Maksimal 10 tanda tangan tersimpan per user.

3. Upload Signature (PRIVATE)
═══════════════════════════════════════════════════════════════════════════════

Mengunggah tanda tangan baru dari file atau canvas drawing. Maksimal 10 tanda tangan per user.

Endpoint: POST /api/signatures/upload

Headers:
Content-Type: multipart/form-data
Cookie: better-auth.session_token=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...

Request Body (FormData):
- file: File (Required, PNG/JPG/JPEG, max 2MB)
- method: "UPLOAD" | "CANVAS" (Required, default: UPLOAD)
- alias: "TTD Formal" (Optional, max 100 characters)

File Constraints:
- Max size: 2MB (2,097,152 bytes)
- Allowed formats: PNG, JPG, JPEG
- Allowed MIME types: image/png, image/jpeg, image/jpg

Request Example (JavaScript):
const formData = new FormData();
formData.append('file', fileInput.files[0]);
formData.append('method', 'UPLOAD');
formData.append('alias', 'TTD Formal');

fetch('http://localhost:3079/api/signatures/upload', {
  method: 'POST',
  credentials: 'include',
  body: formData
});

Request Example (cURL):
curl -X POST "http://localhost:3079/api/signatures/upload" \
  -b cookies.txt \
  -F "file=@signature.png" \
  -F "method=UPLOAD" \
  -F "alias=TTD Formal"

// services/signature.service.ts
import axios from 'axios';

const api = axios.create({
  baseURL: 'http://localhost:3079',
  withCredentials: true // WAJIB untuk cookie
});

export const signatureService = {
  // Get all my signatures
  getMySignatures: async () => {
    const response = await api.get('/api/signatures/me');
    return response.data;
  },

  // Get signature by ID
  getSignatureById: async (id: string) => {
    const response = await api.get(`/api/signatures/${id}`);
    return response.data;
  },

  // Upload signature
  uploadSignature: async (file: File, method: 'UPLOAD' | 'CANVAS', alias?: string) => {
    const formData = new FormData();
    formData.append('file', file);
    formData.append('method', method);
    if (alias) formData.append('alias', alias);

    const response = await api.post('/api/signatures/upload', formData, {
      headers: { 'Content-Type': 'multipart/form-data' }
    });
    return response.data;
  },

  // Update signature alias
  updateAlias: async (id: string, alias: string) => {
    const response = await api.patch(`/api/signatures/${id}`, { alias });
    return response.data;
  },

  // Delete signature
  deleteSignature: async (id: string) => {
    const response = await api.delete(`/api/signatures/${id}`);
    return response.data;
  }
};

// components/SignatureManager.tsx
import { useEffect, useState } from 'react';
import { signatureService } from '../services/signature.service';

interface Signature {
  id: string;
  alias: string;
  method: 'UPLOAD' | 'CANVAS';
  storageUrl: string;
  createdAt: string;
}

export const SignatureManager = () => {
  const [signatures, setSignatures] = useState<Signature[]>([]);
  const [loading, setLoading] = useState(true);
  const [maxAllowed, setMaxAllowed] = useState(10);

  useEffect(() => {
    loadSignatures();
  }, []);

  const loadSignatures = async () => {
    setLoading(true);
    try {
      const response = await signatureService.getMySignatures();
      setSignatures(response.data.signatures);
      setMaxAllowed(response.data.maxAllowed);
    } catch (err) {
      console.error('Failed to load signatures:', err);
    } finally {
      setLoading(false);
    }
  };

  const handleUpload = async (e: React.ChangeEvent<HTMLInputElement>) => {
    const file = e.target.files?.[0];
    if (!file) return;

    // Validate file size
    if (file.size > 2 * 1024 * 1024) {
      alert('File terlalu besar. Maksimal 2MB');
      return;
    }

    // Validate file type
    if (!['image/png', 'image/jpeg', 'image/jpg'].includes(file.type)) {
      alert('Format file tidak didukung. Hanya PNG dan JPG yang diperbolehkan');
      return;
    }

    const alias = prompt('Nama tanda tangan (opsional):');

    try {
      await signatureService.uploadSignature(file, 'UPLOAD', alias || undefined);
      alert('Tanda tangan berhasil diunggah');
      loadSignatures();
    } catch (err: any) {
      alert(err.response?.data?.message || 'Gagal mengunggah tanda tangan');
    }
  };

  const handleUpdateAlias = async (id: string, currentAlias: string) => {
    const newAlias = prompt('Nama tanda tangan baru:', currentAlias);
    if (!newAlias) return;

    try {
      await signatureService.updateAlias(id, newAlias);
      alert('Alias berhasil diperbarui');
      loadSignatures();
    } catch (err: any) {
      alert(err.response?.data?.message || 'Gagal memperbarui alias');
    }
  };

  const handleDelete = async (id: string) => {
    if (!confirm('Apakah Anda yakin ingin menghapus tanda tangan ini?')) {
      return;
    }

    try {
      await signatureService.deleteSignature(id);
      alert('Tanda tangan berhasil dihapus');
      loadSignatures();
    } catch (err: any) {
      alert(err.response?.data?.message || 'Gagal menghapus tanda tangan');
    }
  };

  if (loading) return <div>Loading...</div>;

  return (
    <div>
      <h2>Manajemen Tanda Tangan</h2>
      
      <div>
        <p>Jumlah: {signatures.length} / {maxAllowed}</p>
        {signatures.length < maxAllowed && (
          <div>
            <label htmlFor="upload-signature">
              <input
                id="upload-signature"
                type="file"
                accept=".png,.jpg,.jpeg"
                onChange={handleUpload}
                style={{ display: 'none' }}
              />
              <button onClick={() => document.getElementById('upload-signature')?.click()}>
                Upload Tanda Tangan Baru
              </button>
            </label>
          </div>
        )}
      </div>

      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(200px, 1fr))', gap: '1rem', marginTop: '1rem' }}>
        {signatures.map((sig) => (
          <div key={sig.id} style={{ border: '1px solid #ccc', padding: '1rem', borderRadius: '8px' }}>
            <img src={sig.storageUrl} alt={sig.alias} style={{ width: '100%', height: 'auto' }} />
            <h4>{sig.alias || 'Tanpa Nama'}</h4>
            <p>Method: {sig.method}</p>
            <p>Upload: {new Date(sig.createdAt).toLocaleDateString('id-ID')}</p>
            <button onClick={() => handleUpdateAlias(sig.id, sig.alias)}>
              Edit Nama
            </button>
            <button onClick={() => handleDelete(sig.id)}>
              Hapus
            </button>
          </div>
        ))}
      </div>

      {signatures.length === 0 && (
        <p>Belum ada tanda tangan tersimpan. Upload tanda tangan pertama Anda!</p>
      )}
    </div>
  );
};

// components/SignatureCanvas.tsx
import { useRef, useState } from 'react';
import { signatureService } from '../services/signature.service';

export const SignatureCanvas = ({ onSaved }: { onSaved: () => void }) => {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const [isDrawing, setIsDrawing] = useState(false);
  const [saving, setSaving] = useState(false);

  const startDrawing = (e: React.MouseEvent<HTMLCanvasElement>) => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    setIsDrawing(true);
    const rect = canvas.getBoundingClientRect();
    ctx.beginPath();
    ctx.moveTo(e.clientX - rect.left, e.clientY - rect.top);
  };

  const draw = (e: React.MouseEvent<HTMLCanvasElement>) => {
    if (!isDrawing) return;

    const canvas = canvasRef.current;
    if (!canvas) return;

    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    const rect = canvas.getBoundingClientRect();
    ctx.lineTo(e.clientX - rect.left, e.clientY - rect.top);
    ctx.strokeStyle = '#000';
    ctx.lineWidth = 2;
    ctx.lineCap = 'round';
    ctx.stroke();
  };

  const stopDrawing = () => {
    setIsDrawing(false);
  };

  const clearCanvas = () => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    const ctx = canvas.getContext('2d');
    if (!ctx) return;

    ctx.clearRect(0, 0, canvas.width, canvas.height);
  };

  const saveSignature = async () => {
    const canvas = canvasRef.current;
    if (!canvas) return;

    setSaving(true);
    try {
      // Convert canvas to blob
      const blob = await new Promise<Blob>((resolve) => {
        canvas.toBlob((blob) => resolve(blob!), 'image/png');
      });

      // Create file from blob
      const file = new File([blob], 'signature.png', { type: 'image/png' });

      const alias = prompt('Nama tanda tangan (opsional):');

      await signatureService.uploadSignature(file, 'CANVAS', alias || undefined);
      alert('Tanda tangan berhasil disimpan');
      clearCanvas();
      onSaved();
    } catch (err: any) {
      alert(err.response?.data?.message || 'Gagal menyimpan tanda tangan');
    } finally {
      setSaving(false);
    }
  };

  return (
    <div>
      <h3>Buat Tanda Tangan dengan Canvas</h3>
      <canvas
        ref={canvasRef}
        width={400}
        height={200}
        style={{ border: '1px solid #000', cursor: 'crosshair' }}
        onMouseDown={startDrawing}
        onMouseMove={draw}
        onMouseUp={stopDrawing}
        onMouseLeave={stopDrawing}
      />
      <div>
        <button onClick={clearCanvas}>Clear</button>
        <button onClick={saveSignature} disabled={saving}>
          {saving ? 'Menyimpan...' : 'Simpan Tanda Tangan'}
        </button>
      </div>
    </div>
  );
};

// components/SignatureSelector.tsx
import { useEffect, useState } from 'react';
import { signatureService } from '../services/signature.service';

interface SignatureSelectorProps {
  onSelect: (signatureUrl: string, signatureId: string) => void;
}

export const SignatureSelector = ({ onSelect }: SignatureSelectorProps) => {
  const [signatures, setSignatures] = useState([]);
  const [selected, setSelected] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    loadSignatures();
  }, []);

  const loadSignatures = async () => {
    setLoading(true);
    try {
      const response = await signatureService.getMySignatures();
      setSignatures(response.data.signatures);
    } catch (err) {
      console.error('Failed to load signatures:', err);
    } finally {
      setLoading(false);
    }
  };

  const handleSelect = (sig: any) => {
    setSelected(sig.id);
    onSelect(sig.storageUrl, sig.id);
  };

  if (loading) return <div>Loading signatures...</div>;

  if (signatures.length === 0) {
    return (
      <div>
        <p>Belum ada tanda tangan tersimpan.</p>
        <p>Upload tanda tangan baru atau gunakan canvas untuk membuat tanda tangan.</p>
      </div>
    );
  }

  return (
    <div>
      <h4>Pilih Tanda Tangan Tersimpan</h4>
      <div style={{ display: 'grid', gridTemplateColumns: 'repeat(auto-fill, minmax(150px, 1fr))', gap: '1rem' }}>
        {signatures.map((sig: any) => (
          <div
            key={sig.id}
            onClick={() => handleSelect(sig)}
            style={{
              border: selected === sig.id ? '2px solid blue' : '1px solid #ccc',
              padding: '0.5rem',
              borderRadius: '8px',
              cursor: 'pointer'
            }}
          >
            <img src={sig.storageUrl} alt={sig.alias} style={{ width: '100%', height: 'auto' }} />
            <p style={{ textAlign: 'center', fontSize: '0.9rem' }}>{sig.alias || 'Tanpa Nama'}</p>
          </div>
        ))}
      </div>
    </div>
  );
};

🚨 Common Errors
═══════════════════════════════════════════════════════════════════════════════

Status | Error                                          | Solusi
-------+------------------------------------------------+----------------------------------------
400    | File tanda tangan wajib diupload               | Pastikan file terkirim dalam FormData
400    | File terlalu besar. Maksimal 2MB               | Compress atau resize file < 2MB
400    | Format file tidak didukung                     | Hanya PNG dan JPG yang diperbolehkan
400    | Maksimal 10 tanda tangan per user              | Hapus tanda tangan lama dulu
400    | Alias maksimal 100 karakter                    | Gunakan nama lebih pendek
400    | Tanda tangan sedang digunakan                  | Tidak dapat dihapus jika sedang dipakai
401    | Unauthorized                                   | Session expired, login ulang
403    | Anda tidak memiliki akses                      | Hanya bisa akses TTD sendiri
404    | Tanda tangan tidak ditemukan                   | ID tidak valid atau sudah dihapus
500    | Internal Server Error                          | Cek server logs

📌 Important Notes
═══════════════════════════════════════════════════════════════════════════════

1. **Storage**:
   - Signatures stored in MinIO/S3 bucket
   - Path: signatures/{userId}/{uuid}-{filename}
   - Only accessible by owner
   - Deleted from storage when deleted from DB

2. **Security**:
   - User can only access their own signatures
   - Cannot view/use other user's signatures
   - Storage URLs are signed/private
   - Deletion validation prevents removing active signatures

3. **File Constraints**:
   - Max size: 2MB (smaller than attachment max of 5MB)
   - Only PNG/JPG formats (for transparency and quality)
   - Frontend should validate before upload

4. **Limits**:
   - Max 10 signatures per user (prevents storage abuse)
   - Must delete old signatures to upload new ones
   - No bulk upload supported

5. **Methods**:
   - UPLOAD: Uploaded from file system
   - CANVAS: Created using canvas drawing
   - Both stored as PNG in storage

6. **Alias**:
   - Optional friendly name for signature
   - Max 100 characters
   - Can be updated anytime
   - Helps distinguish multiple signatures

7. **Best Practices**:
   - Recommend transparent PNG background
   - Suggest standard signature size (e.g., 400x200px)
   - Provide template/guide for manual signatures
   - Auto-crop whitespace for canvas signatures
   - Optimize file size before storage

8. **Future Enhancements** (not implemented yet):
   - Biometric signature capture
   - Digital certificate integration
   - Signature verification/validation
   - Version history
   - Signature expiry dates
   - Multi-signature support (different roles)
